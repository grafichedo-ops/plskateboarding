# Font Cubano

`next/font/local` in `app/layout.tsx` si aspetta il file qui:

- `Cubano.woff2`

Cubano è un font a pagamento/licenza (Fontfabric). Procuratelo dalla fonte
ufficiale e converti in woff2 se necessario (es. con
https://cloudconvert.com/ttf-to-woff2 oppure `fonttools` in locale).

Inter invece è caricato automaticamente da Google Fonts via
`next/font/google`, nessuna azione richiesta.
